# Música de fondo

Coloca aquí el archivo de música de fondo, por ejemplo:

    cancion-para-valeria.mp3

Luego verifica que el nombre coincida con:
- `rutaMusica` en `js/config.js`
- La etiqueta `<source>` dentro de `index.html`

Se recomienda una canción suave e instrumental, en formato MP3, de menos
de 5 MB para no afectar el tiempo de carga del sitio.
